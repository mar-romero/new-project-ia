# Definition of Done

A task is done only when all applicable items have evidence.

- [ ] Acceptance criteria are satisfied and scope stayed contained.
- [ ] Relevant formatting, lint, static/type, schema and test checks pass.
- [ ] External contracts and documentation changed where behavior changed.
- [ ] No secret, unsafe permission or unauthorized side effect was added.
- [ ] Independent review completed for meaningful R1/R2/R3 work.
- [ ] No unresolved blocker or high finding remains.
- [ ] Required specialist review and human decisions are complete.
- [ ] Completion report records exact commands, residual risks and rollback.

Mark a check N/A only when it is genuinely irrelevant.
