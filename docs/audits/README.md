# Audit Evidence

Store durable review evidence for important tasks, not raw agent
conversations. A report should state task, candidate revision/diff, review
scope, evidence inspected, findings, verdict and residual risks.

Normally persist material specialist review for R2 and all required review for
R3. For an ordinary R1 task, the completion report is usually sufficient
unless findings have lasting value. Do not store credentials or unnecessary
source dumps.
