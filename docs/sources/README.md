# External Source Knowledge

Store compact, implementation-relevant contracts for external APIs, datasets,
protocols and libraries. Do not copy whole vendor documentation.

Prefer official documentation, specifications, official source repositories and
release notes. Record unknown behavior as `UNKNOWN / NOT DOCUMENTED`; never
replace it with a guess. Revisit a contract when the provider/version changes
or observed behavior no longer matches it.

Each contract should identify the source, interface/version, fields used,
authentication/permissions, request and response shape, time/units where
relevant, limits, errors, known limitations and verification date.
